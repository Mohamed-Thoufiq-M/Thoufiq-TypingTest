# ⚡ Thoufiq - Typing Test

A sleek, minimalist, and responsive web-based typing speed test built with HTML5, CSS3, and Vanilla JavaScript. Designed for high accuracy, smooth feedback, and zero ad distractions.

🚀 **Live Demo:** (https://Mohamed-Thoufiq-M.github.io/thoufiq-typing-test/)

---

## ✨ Features

* 🎯 **Multiple Modes:** Test by Time (15s, 30s, 60s), Word Count (10, 25, 50), or Zen mode.
* 🎨 **Custom Themes:** Toggle between Cyber Glass, Neon Matrix, and Synthwave aesthetics.
* 🔊 **Audio Feedback:** Web Audio API key clicks and error chimes.
* 📊 **Live Analytics:** Instant WPM, Raw WPM, Accuracy %, and a interactive speed chart powered by Chart.js.
* 💀 **Game Modifiers:** Includes Sudden Death (fail on error) and Blind Mode.
* 📱 **Fully Responsive:** Smooth glassmorphic interface that scales dynamically across screen sizes.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Glassmorphism)
* **Logic:** Vanilla JavaScript (ES6+)
* **Libraries:** [Chart.js](https://www.chartjs.org/) for performance visualization
